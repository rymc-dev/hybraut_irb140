\subsection {issues/future improvements}

this is a prototype version of the end effector designed,
we had some isuses when actually assembling the end effector
these issues were two fold, first was that the reference sketches
I utilized of the finger mounts did not give me the correct distance 
between the mounting holes on the sides of the finger mounts so in future 
the mounting arms need to be spaced out approx 2mm further to solve this
we threaded drilled thought the mounting hole on the finger hold 
by a tiny margin to give the leeway for assembling it. secondly we did not 
have the M4x35mm screws from the cad assembly so the tool flange end effector adapter 
neck should in future be made shorter to account for 30mm length instead to solve this problem,
we grinded the 50mm M3 screws down by 20mm so we could properly mount the end effector. 

One final problem we had was that the material of the fingers silicon did not have a high pressure
tolerance therefore we had to be extermely careful with pressure regulators connected to the solonoid valves
to ensure that we did not blow up the fingers, this was fine but in future it may be useful to utilzie 
a strong material to alleviate the worrys as this would have been a time costly issues if it blew up on me.
